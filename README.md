# בינה בהבנה - קורס בינה מלאכותית למתחילים

דף נחיתה עבור קורס "בינה בהבנה" - קורס מבוא ידידותי למתחילים בעולם הבינה המלאכותית.

## אודות הפרויקט

דף נחיתה זה נועד לספק מידע על קורס "בינה בהבנה". הקורס מיועד לאנשים ללא רקע טכנולוגי קודם המעוניינים להבין את יסודות הבינה המלאכותית, ללמוד על כלים שימושיים ולגלות את ההשפעה של AI על חיינו.

דף הנחיתה כולל את המקטעים הבאים:

* **הצגה (Hero Section):** כותרת מרכזית, תיאור קצר וכפתור קריאה לפעולה.
* **יתרונות הקורס (Benefits Section):** פירוט היתרונות של לימוד בקורס "בינה בהבנה".
* **מה תלמדו בקורס? (Course Details Section):** סקירה של הנושאים הנלמדים בקורס.
* **קריאה לפעולה (Call to Action Section):** הזמנה להצטרף לקורס עם קישור להרשמה או לקבלת פרטים נוספים.
* **פוטר (Footer):** מידע על זכויות יוצרים וקישורים נוספים.

## טכנולוגיות בשימוש

* **HTML:** מבנה הדף.
* **CSS:** עיצוב הדף (כולל שימוש ב-Bootstrap לעיצוב רספונסיבי).
* **Bootstrap Icons:** ספריה של אייקונים.
* **Google Fonts:** פונטים מותאמים אישית (Assistant ו-Rubik).
* **JavaScript:** עבור פונקציונליות בסיסית (עדכון שנת הפוטר).

## התקנה ושימוש (עבור GitHub Pages)

1.  **העלה את כל קבצי הפרויקט (קובץ ה-HTML, תיקיית `img` עם התמונה `img1.png`, וכו') למאגר GitHub.**
2.  **עבור להגדרות המאגר שלך ב-GitHub.**
3.  **גלול מטה ומצא את סעיף "GitHub Pages".**
4.  **בחר את הענף (Branch) הראשי שלך (בדרך כלל `main` או `master`) בתור המקור.**
5.  **בחר את תיקיית השורש (`/`) בתור התיקייה.**
6.  **לחץ על "Save".**
7.  **האתר שלך יהיה זמין בכתובת URL בפורמט `https://<שם המשתמש שלך>.github.io/<שם המאגר שלך>`.**

## שימוש מקומי (לפיתוח ובדיקה)

1.  **שמור את קובץ ה-HTML ואת תיקיית `img` (עם התמונה) בתיקייה אחת במחשב שלך.**
2.  **פתח את קובץ ה-HTML באמצעות דפדפן האינטרנט שלך (פשוט לחץ עליו פעמיים).**
